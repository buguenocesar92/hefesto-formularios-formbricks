# Tres cuestionarios para crear en el editor
Son guías de configuración, no JSON importable ni encuestas ya creadas. Publicar primero una copia de prueba sin datos personales reales. Validar los tipos y saltos disponibles en la edición instalada; no depender de una función Enterprise sin licencia.

## 1. Solicitud de proyecto Hefesto
Título: Cuéntanos qué necesitas construir.
Introducción: revisaremos tu solicitud para coordinar el siguiente paso. Indicar el uso de los datos y enlazar la política real de Hefesto; no prometer plazos que aún no se han definido.

- Nombre: texto corto, requerido.
- Correo: campo email, requerido.
- Empresa/proyecto: texto corto, opcional.
- Necesidad: selección entre tienda online, gestión/Odoo, automatización, aplicación web, soporte u otra.
- Descripción: texto largo, requerido; aviso de no incluir contraseñas.
- Plazo deseado: selección este mes / 1–3 meses / por definir.
- Presupuesto orientativo: rangos que Hefesto defina antes de publicar; permitir por definir.
- Contacto autorizado: aceptación separada de contacto para esta solicitud; requerida para enviar a CRM.
- Marketing: opción independiente y opcional; no tratarla como autorización necesaria para responder la solicitud.

Cierre: solicitud recibida; describir el próximo paso sin disparar reuniones/cobros automáticamente. Exportación a Odoo con el conversor y columnas explícitas.

## 2. Satisfacción después de una entrega
Título: ¿Cómo resultó tu experiencia con Hefesto?

- Satisfacción general: escala 1–5, requerida, con extremos claramente definidos.
- ¿Qué funcionó mejor?: texto largo opcional.
- ¿Qué debemos mejorar?: texto largo opcional.
- ¿Recomendarías Hefesto?: escala 0–10 si el tipo está disponible; alternativa selección 0–10.
- ¿Quieres que revisemos tu comentario contigo?: sí/no, opcional.
- Correo de contacto: opcional; solicitar solo a quienes quieran seguimiento (salto si la edición lo permite, o instrucción visible).

Evitar pedir RUT o datos sensibles. Para anonimato real, revisar configuración/identificadores y no compartir enlaces con identificación personalizada. No afirmar anonimato solo porque no se pidió el nombre. Comparar respuestas por proyecto sin exponer comentarios entre clientes.

## 3. Diagnóstico de procesos y automatización
Título: Detectemos tareas que consumen tiempo.

- Área: ventas, administración, inventario, soporte, otra.
- Tarea repetitiva: descripción requerida.
- Frecuencia: diaria, semanal, mensual, eventual.
- Tiempo por ejecución: estimación numérica en minutos, opcional.
- Herramientas actuales: selección múltiple Odoo / WordPress-WooCommerce / planillas / correo / WhatsApp / otra.
- Resultado esperado: texto requerido.
- Responsable y correo: contacto opcional; consentimiento de seguimiento separado.

No recopilar credenciales, bases de clientes ni documentos confidenciales. Cierre: diagnóstico inicial sujeto a revisión; no calcular ahorro garantizado solo con estas respuestas.

## Entrega al cliente
Registrar propietario, finalidad, preguntas aprobadas, audiencia, URL de encuesta, plazo de publicación, acceso a exportaciones y retención. Probar móvil, teclado, mensajes de error y envío completo. Cerrar o archivar encuestas según el acuerdo y exportar solo a los responsables autorizados.
