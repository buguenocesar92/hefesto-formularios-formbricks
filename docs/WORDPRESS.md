# WordPress y WooCommerce
La integración inicial más simple consiste en un botón o enlace al formulario publicado por la instancia. Crear y probar primero una encuesta; copiar su URL pública exacta desde Formbricks y usarla en un botón de WordPress o en una página de atención/postventa de WooCommerce. No usar la URL del editor ni credenciales del panel.

Para satisfacción postventa, añadir el enlace al contenido del correo o a la página que el responsable del comercio elija, después de revisar el contexto y la política de contacto. Esta entrega no modifica una tienda ni instala un plugin o automatización que envíe mensajes a compradores.

No incluir email, RUT ni otros datos personales en parámetros del enlace por comodidad. Si se adopta una integración con identificación, revisar permisos, exposición de URLs y consentimiento antes de implementarla. El SDK/widget y cualquier disparador automático deben probarse contra esta versión y su licencia; no se dan por instalados.
